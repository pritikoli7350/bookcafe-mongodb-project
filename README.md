
# ☕ BookCafe Management System

A modern cafe ordering and management system built using Flask and MongoDB.  
This project allows users to place coffee orders while providing an admin dashboard to manage, edit, and delete orders.


## Features

### User Features
- View cafe menu
- Select coffee items with quantity
- Place orders easily
- Order success confirmation page

### Admin Features
- View all customer orders
- Edit existing orders
- Add new items while editing
- Delete orders from database
- Automatic total price calculation
